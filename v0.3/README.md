## v0.3 相较于 v0.2 的改动

### 🖥️ 界面：控制台 → Swing GUI（核心升级）

| 模块 | v0.2（控制台） | v0.3（GUI） |
|------|---------------|-------------|
| 登录 | `Scanner` 逐行输入 | JFrame 窗口 + 文本框 + 验证码 |
| 注册 | 控制台逐字段输入 + 验证 | GUI 表单 + 实时格式提示 + 独立错误消息 |
| 忘记密码 | `Scanner` + 手机号验证 | GUI 表单 + 手机号独立校验 |
| 修改密码 | 无 | GUI 表单 + 旧密码验证 |
| 角色创建 | 控制台分配 20 点属性 | 可视化四列面板 + +/-/All 按钮 + 一键平均分配 |
| 战斗 | 控制台文字输出 | 敌我血条 + 滚动日志 + 按钮操作 |

### ⚔️ 战斗系统交互升级

| 功能 | v0.2 | v0.3 |
|------|------|------|
| 技能选择 | 输数字编号 | 按钮面板，MP 不足自动灰色禁用 |
| 道具选择 | 输数字编号 | 按钮面板，背包为空时提示 |
| 战斗日志 | `System.out.println` | JTextArea 滚动日志，自动滚底 |
| 回合显示 | 无 | `━━━ 第 N 回合 ━━━` 分隔线 |
| 防御姿态 | 伤害计算有 bug（显示原始伤害） | 正确显示减半后伤害 + 日志提示 |
| 战后 | 自动下一场 | 弹窗选择：继续战斗 / 返回主菜单 |
| 血条 | 纯文本 | `[████░░]` + 颜色（绿/橙/红） |

### 🎯 体验增强

- **回车键绑定**：登录/注册/忘记密码/修改密码页面的主按钮均支持回车提交
- **输入提示**：鼠标移到输入框自动显示格式要求，键入后自动消失
- **防御状态指示**：角色名后显示 `[DEFENDING]`
- **道具使用提示**：使用道具后日志显示 `，回合结束` 明确告知跳过攻击
- **战前休整**：每场战斗前自动恢复 15% HP + 日志提示
- **BattleTip 语录**：击败/阵亡/HP 警告/MP 不足四大类随机语录
- **无闪屏切换**：Login 和 FightingGame 通过引用传递，返回时不重建窗口
- **用户数据持久**：`static list` 确保重新登录不丢失注册的账号

### 🔧 代码质量

| 项目 | v0.2 | v0.3 |
|------|------|------|
| Login 代码量 | ~700 行 | ~450 行（-35%） |
| FightingGame 代码量 | ~1260 行 | ~700 行（-44%） |
| 死代码 | `Scanner` 方法 360 行 + 空 Override 120 行 | 全部清理 |
| 未使用 import | `Scanner`, `MouseListener`, `KeyListener` | 已移除 |
| 控制台依赖 | `System.in` / `System.out` 用于交互 | 完全移除 |
| `tips()` 方法 | `Object` 参数 + `JPasswordField.getText()` 废弃警告 | `JTextComponent` 参数，零警告 |

## 运行

```bash
cd v0.3

# 编译
javac -encoding UTF-8 -d out/production/v0.2 -sourcepath src src/com/xiaogan/App.java

# 运行
java -cp out/production/v0.2 com.xiaogan.App
```

或用 IDE（IntelliJ IDEA）打开运行 `App.java`。

> 背景图：`image/backGround/backGround.jpeg`，请确保图片存在。控制台版本（v0.2/v0.1）不需要图片。

## 战斗系统速览

### 伤害公式

```
伤害 = 攻击力 × 100 ÷ (100 + 防御力)    防御姿态：伤害再减半
```

- 0 防 → 吃满 100% · 100 防 → 吃 50% · 200 防 → 吃 33%

### 技能（6 个）

| 技能 | 消耗 | 类型 | 效果 |
|------|------|------|------|
| 强力一击 | 10 MP | ATTACK | 1.8× ×1hits |
| 二连斩 | 8 MP | ATTACK | 0.8× ×2hits |
| 生命汲取 | 10 MP | HEAL_HP | 恢复 30% 最大 HP |
| 冥想 | 0 MP | HEAL_MP | 恢复 50% 最大 MP |
| 战吼 | 12 MP | BUFF | 永久 +4 ATK |
| 铁壁 | 12 MP | DEFENSE | 下回合受伤减半 |

### 敌人（8 种）

| 敌人 | HP | ATK | DEF | 技能 |
|------|-----|-----|-----|------|
| 初级战士 | 100 | 18 | 12 | 猛击 1.5× |
| 敏捷刺客 | 70 | 25 | 5 | 快速攻击 0.9× ×2 |
| 重装坦克 | 150 | 8 | 22 | 防御姿态 |
| 神秘法师 | 80 | 30 | 6 | 火球术 1.8× |
| 暗黑领主 | 200 | 35 | 20 | 暗影爆裂 2.0× |
| 狂战士 | 110 | 28 | 8 | 狂暴连击 0.7× ×3 |
| 石像鬼 | 140 | 20 | 28 | 石化打击 1.5× |
| 冰霜女巫 | 95 | 32 | 7 | 冰霜风暴 0.9× ×2 |

### 平衡性

- 战后恢复 20% HP & MP · 战前休整 15% HP
- 每 3 胜永久提升：HP+30 / MP+20 / ATK+5 / DEF+3
- 敌人每场成长：+8 HP / +2 ATK / +1 DEF
- 道具掉落 20% 概率
